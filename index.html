AI agents · 2026

Sentinel — an operations agent with guardrails

An agent for inbound support work that triages each ticket, drafts a reply, runs approved actions, verifies its own claims, and escalates anything uncertain to a human.

  • Splits fast typed judgments (triage, routing, safety checks) from slower LLM generation, with plain code as the final authority on every action.
  • Destructive tools never run without human approval, and prompt-injected tickets can't issue refunds or close accounts. Both are covered by tests.
  • PII redaction before any model call, a full audit log with model IDs, latency and cost, and an eval suite over 67 hand-labelled tickets.
